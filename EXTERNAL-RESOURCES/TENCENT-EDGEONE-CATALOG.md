## Selection rationale

1. Tech Stack Analyzer is the most reusable addition to our general workflow: inspect first, then modify.
2. Website Skeleton is a strong reference for full-stack modules, but its Next.js/EdgeOne assumptions must remain explicit.
3. PortfolioFlow contributes dashboard, theme, analytics, and polished presentation patterns.
4. Academic Hub is especially relevant to our educational platform work, but is a React reference implementation.
5. SaaS Landing Page Generator is retained as a design reference pending complete package/license verification.
