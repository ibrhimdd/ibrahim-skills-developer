## Included skills
- `motion-design`: timing, spacing, easing, composition, anticipation, follow-through, and general motion craft.
- `aftereffects-motion`: After Effects workflows, ExtendScript, effects, and optional MCP control.
- `blender-motion`: Blender keyframing, materials, lighting, cameras, F-curves, drivers, geometry nodes, and rendering.
- `motion-design-critique`: review and diagnose motion and rendering problems.

## Best use
Professional motion graphics, animated titles, 3D scenes, product animation, and motion critique.

## Scope limitation
The repository explicitly excludes web motion (GSAP, Framer Motion, R3F). For website animation, consult Scrolltide and web-native animation tools instead.

## Optional MCP integrations
After Effects MCP and Blender MCP can connect the agent to running applications, but each requires separate local installation and configuration. The skills can still be used as reference without MCP. No such local integration is configured by this library entry.
