# Remotion Agent Skills — remotion-dev

- **Category:** Official Agent Skills for the Remotion video framework
- **Repository:** https://github.com/remotion-dev/skills
- **Documentation:** https://www.remotion.dev/docs/ai/skills
- **Reviewed:** 2026-11-13

## Installation command from the source
```bash
npx skills add remotion-dev/skills
```

## Available skill areas
- Best practices and project creation.
- React-based video markup, animation, layout, typography, media, and audio.
- Remotion Studio preview and video rendering.
- Animated maps, routes, and geographic explainers.
- Captions and subtitles.
- Remotion-powered SaaS architecture and interactivity.
- Documentation lookup, license information, and upgrades.

## Best use
Programmatic video creation with React, product promos, animated explainers, maps, captions, and automated video pipelines.

## Compatibility
Requires a React/Remotion project and its supported Node/browser/rendering environment. It is not a drop-in animation library for a plain PHP page.
