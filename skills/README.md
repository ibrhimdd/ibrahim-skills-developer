This directory contains first-party workflow skills maintained for this repository. Each skill follows the Agent Skills format and lives in its own directory with a `SKILL.md` entry point.

## Usage

1. Open the skill directory relevant to the task.
2. Read its complete `SKILL.md` before planning or editing.
3. Follow its project-inspection, compatibility, safety, and verification steps.
4. Treat external resources as references; inspect their current upstream instructions before installing or copying anything.

These are guidance files, not installed software. An agent/client must support the Agent Skills format and have this repository or the selected skill directory available.
